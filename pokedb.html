Karty
GET /api/v1/cards Vyhledávání a filtrování karet ›
Vrací stránkovaný seznam karet. Podporuje fulltextové vyhledávání, filtrování a řazení.
Query parametry
qstringFulltextové vyhledávání (jméno, CS jméno)
set_idstringID série (např. sv6)
typestringTyp energie (Fire, Water, Grass…)
supertypestringPokémon | Trainer | Energy
raritystringVzácnost (Common, Rare, Rare Holo…)
hp_minintegerMinimální HP
hp_maxintegerMaximální HP
sortstringname | hp | -hp | -id | number (prefix - = desc)
pageintegerStránka (výchozí: 1)
limitintegerVýsledků na stránku, max 100 (výchozí: 36)

🔑 Získat API klíč

Bezplatný klíč dává 1 000 požadavků za hodinu. Po registraci obdržíš klíč – uchovej ho, zobrazí se jen jednou.

Tvůj API klíč – zkopíruj ho teď!
⚠️ Klíč se zobrazí pouze jednou. Ulož si ho na bezpečné místo.
Jak klíč používat
// Header (doporučeno)
fetch('/api/v1/cards?q=Charizard', {
  headers: { 'X-API-Key': 'pk_live_xxx' }
})

// Query parametr
fetch('/api/v1/cards?q=Charizard&api_key=pk_live_xxx')
